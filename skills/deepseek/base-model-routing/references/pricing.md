# DeepSeek pricing reference (checked 2026-10-20)

USD per million tokens. Source: https://api-docs.deepseek.com/quick_start/pricing

| Tier | Model | Input | Output | Applies to |
|---|---|---:|---:|---|
| T1 | DeepSeek V4.1 Flash (non-thinking) (`deepseek-flash`) | $0.30 | $1.20 | all prompt sizes |
| T2 | DeepSeek V4.1 Flash (thinking) (`deepseek-flash`) | $0.30 | $1.20 | all prompt sizes |
| T3 | DeepSeek V4 Pro (`deepseek-v4-pro`) | $1.32 | $3.96 | all prompt sizes |
| T4 | DeepSeek V4 Pro (max effort) (`deepseek-v4-pro`) | $1.32 | $3.96 | all prompt sizes |

- Calculated at peak-hour prices. Off-peak prices are half, which lowers both sides equally and does not change the percentages.
- DeepSeek has no model above V4 Pro, so T4 means V4 Pro at maximum reasoning effort. For the rarest, highest-stakes calls, a second opinion from another provider is a reasonable T4.

Prices change. Re-check the source page before quoting numbers.
